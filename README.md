# Bricky Dubai Real Estate API

Dubai real estate transaction data API for developers, analysts, researchers and PropTech applications.

Bricky provides structured access to recent and historical Dubai property transaction data through a REST API.

## What data is available?

The API provides access to Dubai real estate transactions including:

- Property transaction prices
- Price per square meter
- Transaction dates
- Areas and buildings
- Number of rooms
- Property usage
- Registration type
- Parking information
- Recent and historical transactions

## Use cases

Bricky API can be used to build:

- Property valuation tools
- Dubai real estate dashboards
- Market research platforms
- Investment analytics
- PropTech applications
- Property market monitoring tools
